# Hospital Queue - Mini Aplicação

Este é um projeto simples em Java que simula o gerenciamento de uma fila de hospital, utilizando a estrutura de dados **Fila (Queue)**. O objetivo principal da aplicação é demonstrar o uso da fila para organizar e processar o atendimento de pacientes.

## 📋 Funcionalidades

- Adicionar pacientes à fila de atendimento.
- Chamar o próximo paciente para consulta.
- Exibir pacientes já chamados.

## 🚀 Como Executar

### 1️⃣ Clonar o Repositório

```sh
git clone -b queue-manager git@github.com:guilhermepereiradev/estrutura-de-dados.git
cd estrutura-de-dados/queue-manager
```

### 2️⃣ Compilar o Código

```sh
javac -d out src/*.java src/com/oxd/queue/*.java src/com/oxd/hospital/*.java
```
```sh
java -cp out Main
```

## 🛠️ Tecnologias Utilizadas

- **Java**: Linguagem de programação principal.
- **Estrutura de Dados - Fila (Queue)**: Utilizada para gerenciar a ordem de atendimento dos pacientes.
