# Stack Manager

Este é um projeto simples em Java que simula um histórico navegação básico, utilizando a estrutura de dados **Pilha (Stack)**. O objetivo principal da aplicação é demonstrar o uso da pilha para armazenar e gerenciar o histórico de navegação.

## 📋 Funcionalidades

- Navegar para novas páginas e armazená-las na pilha.
- Retroceder para a página anterior
- Visualizar a página atual.
- Avançar para uma próxima página.

## 🚀 Como Executar

### 1️⃣ Clonar o Repositório

```sh
git clone -b stack-manager git@github.com:guilhermepereiradev/estrutura-de-dados.git
cd estrutura-de-dados/stack-manager
```

### 2️⃣ Compilar o Código

```sh
javac -d out src/*.java src/com/oxd/stack/*.java src/com/oxd/website/*.java
```

### 3️⃣ Executar a Aplicação

```sh
java -cp out Main
```

## 🛠️ Tecnologias Utilizadas

- **Java**: Linguagem de programação principal.
- **Estrutura de Dados - Pilha (Stack)**: Utilizada para armazenar e gerenciar o histórico de navegação.
